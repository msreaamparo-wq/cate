# Chelsea Kate Casing — Portfolio

A responsive, editorial-style personal portfolio built with plain HTML, CSS, and JavaScript. It uses the uploaded profile photo stored at `assets/chelsea-kate-casing.jpg`.

## Preview locally

1. Download and extract the ZIP.
2. Open `index.html` in your browser. No build step or package installation is needed.

## Publish with GitHub Pages

1. Create a GitHub repository. For a free public site, set the repository to **Public**.
2. Upload the *contents* of this folder (not the ZIP itself) so that `index.html` is at the repository root.
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then click **Save**.
5. Wait for the build to finish. The website URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
